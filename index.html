    🎓 教程
    第一次用？按 1→8 走一遭，大约 10 分钟就能做出一个能玩的小场景。
    1
    🎬 先选个起点
    第一次打开会问你「字体风格 + 起始内容」，选互动游戏示例或视觉小说示例都行，里面有现成素材可以直接玩。选错了也不怕：设置 → 📖 示例剧本，随时重选。
    2
    👤 新建角色
    点顶部 「＋ 角色」，上传主立绘（可选说话立绘），创建后会自动进入调校：左边拖动立绘、右边滑块微调缩放与位移，直到它刚好坐在对话框上方。点「保存」。
    批量图片多时点弹窗里的 ⚡ 批量。
    3
    🖼 导入背景 / CG
    「素材」面板里是两个独立入口：「＋ 导入背景图」（保留立绘）和 「＋ 导入 CG 插画」（默认隐藏立绘）。都是一次可多选，多选会直接入库。
    CG 导入时可以顺手关联角色，导入后也能在 CG 那一行的 🔗 按钮上随时改。
    4
    💬 写第一句台词
    在「剧本」面板点 「💬 台词」，选发言角色、写内容、插入。你也可以直接在文本框里手写，格式就一行：小明: 你好。
    没有冒号的行会被当成旁白。
    5
    👤 让角色登场
    点 「👤 立绘」，选角色、位置、表情、入场动画，插入后就写成 @show 小明 左 这样的一行。位置支持：最左 / 左 / 中 / 右 / 最右 / 左二 / 右二。
    6
    ▶ 播放预览
    点 「▶ 播放」。点舞台 / 按空格推进，选项点按钮，热点点白星。播放时左上角可开自动播放和倍速。
    想从中间某一句开始试：光标放那一行，点底部 「▶ 从此处播放」。
    7
    🎮 做一张可点的场景
    「素材」→ 「🎮 打开互动场景制作器」：导入底图 → 手指拖框画区域 → 填跳转（可以直接下拉选已有分支，空着就自动建）→ 保存。
    勾上「生成标签骨架」，一段能直接跑的剧本就写好了。
    8
    💾 导出作品
    「💾 导出」 存工程 JSON（下次可导入继续改）；「🎮 导出游戏」 生成一个单独的 HTML，双击就能玩，可以发给朋友。
    两种都建议定期存一份，本地浏览器缓存不可靠。
    9
    📱 在手机上用
    底部导航栏切换面板，面板可上下滑动，弹窗全屏可滚。编辑剧本建议横屏；只想试玩就直接点 ▶ 播放。
    右上角 ⛶ 可以把舞台藏起来，编辑区直接双倍大。
    10
    🎬 加个封面（可选）
    顶部 「🎬 封面」 → 勾选启用 → 点 「📋 填入示例」 → 保存。想改字就改文字，想挪按钮就在预览里拖。
    不想要封面就不勾启用，游戏还是打开即开始。
    这些是把作品从「能玩」推到「好看」的部分，按需取用。
    👤 角色 / 表情 / 说话差分

    角色卡片上每个表情有两张图：常态 与 说话（可空）。说话图会在该角色说话时自动切换，相当于免费的“口型差分”。

    • 点表情缩略图 = 替换图片；点表情名字 = 重命名（会同步剧本里所有旧名字）
    • 卡片右上 ⚙ = 调校：缩放 / 水平位移 / 垂直位移，可存成预设反复用
    • 默认表情决定角色没指定表情时用哪一张；默认入场动画在新建时选
    • 关掉「使用说话立绘」开关，这个角色就不会做口型切换
    @show 小明 左 微笑 slide-left 小明[微笑]: 这句话会切到「微笑」表情。 小明: 不写表情就沿用上一次。 @hide 小明
    🖼 背景 / CG / 拼接
    • 背景：保留立绘，适合日常场景
    • CG：默认隐藏立绘；可用 🔗 关联角色（只是标注，方便对位）；想强制在 CG 上显示立绘，去设置里开「CG 场景中也显示立绘」
    • 点场景行的类型标签可以在「背景 / CG」之间互转，不用重新导入
    • 拼接部分：一张图太窄时，把几张图拼成一屏，播放时用左右箭头翻页
    • 动态图片：支持 GIF / APNG / 动态 WebP，导入方式和普通图片一样，列表里会标「✦ GIF」
    @bg 教室 fade // 淡入切换 @cg 告白 fade // CG 用 @cg 更语义化 @bg 教室 black // 黑屏转场
    🎨 对话框自定义（重点）

    入口：设置 → 🎨 对话框自定义。里面就地预览、即时生效，导出游戏时也会带走。

    能改的四个东西：

    • .dialog 对话框盒子 —— 底色、边框、圆角、阴影、内外边距、宽度
    • .name 名字框 —— 颜色、边框、偏移
    • .text 正文 —— 颜色、行高、字距、字号
    • .avatarBox 头像框 —— 只在「头像」模式下出现

    点「📋 填入模板」会得到一份带注释的起始样式，直接改数字就能看到变化：

    .dialog{ background: linear-gradient(180deg,rgba(10,14,30,.96),rgba(4,6,14,.98)); border: 3px solid #9fd0ff; border-radius: 10px; left: 6%; right: 6%; /* 改宽度 */ box-shadow: 0 10px 30px rgba(0,0,0,.7); } .text{ color:#e8f2ff; line-height:1.85; }
    几个常用配方：
    变窄：.dialog{left:12%;right:12%}
    半透明毛玻璃：background:rgba(0,0,0,.55);backdrop-filter:blur(4px)
    纸片风：background:#f6f1e4;color:#2a2a2a;border-radius:0（正文记得同步改 .text 颜色）
    圆角全去：border-radius:0

    写坏了点「↺ 恢复默认」即可，不会弄丢剧本。

    🌈 主题自定义（界面配色）

    入口：设置 → 🌈 主题与配色。只换编辑器界面的配色，不会影响舞台和播放时的效果。

    • 四种预设：像素黑白（默认）、深夜蓝、纸片、赛博福虹——点一下立刻换
    • 自定义：在文本框里写 CSS，点「✅ 保存为自定义主题」生效
    • 换错了点「↺ 恢复默认」回到像素黑白

    主题就是「把某些选择器重新上色」。常用选择器：

    .topbar → 顶栏 .sidebar → 右侧面板 .tabs → 标签页（按钮） .quickBar → 快捷插入区 .assetItem→ 素材卡片 .stageWrap→ 舞台周围的底板 .editorWrap→ 剧本编辑区

    点「📋 填入模板」会得到一份带全部常用项的起始样式，改颜色数值即可：

    body{ background:#0a0a12; color:#e8e8f4; } .topbar{ background:#0b0b16; border-bottom-color:#6b6bff; } .tabs button.active{ background:#6b6bff; color:#0b0b16; } button{ background:#0d0d18; border-color:#4a4a80; color:#e8e8f4; }
    小技巧：想做浅色主题，把 body 背景改浅色后，记得同步改 .editorWrap .highlight 的文字颜色，不然剧本会看不清楚。
    🎬 开始界面 / 封面

    入口：顶部 🎬 封面。默认不启用——启用后，导出的游戏会先显示封面，点「开始游戏」才进正文；不启用就保持原来的“打开即开始”。

    • 背景：可导入一张图，或只用背景色 + 暗化遮罩
    • 标题：留空就用工程名；也可以上传一张「标题图」当 logo
    • 按钮：在预览里直接拖动定位置，右侧可改文字、动作、宽高、字号、字色、底色、描边、圆角、悬停效果
    • 动作：开始游戏 / 读取存档 / 对话历史 / 致谢表 / 制作信息
    • 一键示例：点「📋 填入示例」直接得到一套三按钮封面
    按钮坐标用的是百分比，所以窗口怎么缩放、手机怎么转屏，位置都不会跑。
    💾 存档与对话历史

    导出的游戏左上角有两个按钮：💾 存档 和 📖 历史。

    • 存档：3 个档位，可存可读，会记住当前场景、立绘、变量、物品和对话框状态
    • 历史：记录最多 400 句已读对话，随时回看
    • 封面上的按钮也可以直接指向「读取存档」「对话历史」
    存档存在玩家本机的浏览器里，换设备或清缓存会丢失；想长期保存请用「💾 导出」工程文件。
    🖼 图片按钮（常态 + 按下）

    封面按钮默认是「纯样式」（文字 + 底色 + 描边）。想用图片做按钮：

    • 选中按钮 → 右侧「类型」选 图片按钮
    • 点 「🖼 常态图」 上传平时显示的图
    • 点 「🖼 按下图」 上传按压时切换的图（可选，但建议两张同尺寸）
    • 图片模式下文字/底色/描边会失效，按钮大小仍由宽高控制
    图片会内嵌进导出的 HTML；两张图建议同尺寸，否则按下时会轻微跳动。
    🎨 存档界面自定义

    封面编辑器右侧面板最下方有「存档界面」一区，改的是游戏里存档/读档弹窗的样子：

    • 标题：默认「存档 / 读档」
    • 背景 / 文字 / 边框 / 强调色：四个颜色一改，弹窗、档位行、按钮都跟着变
    想做成浅色存档页：背景 #f7f2e6、文字 #2a2620、边框 #8d7c5e，马上就是纸质感。
    🎯 热点与互动项

    场景行上的 🎯 打开热点编辑：在图上拖框，框出来的区域就是玩家能点的位置。

    • 首次 / 重复 / 最终三段跳转：第一次点、重复点、达到阈值后分别跳到不同标签
    • 最大触发次数：0 = 无限；到次数后板块自动消失
    • 需求物品：没拿到物品时这个热点不出现
    • 获得物品：点了就给（相当于自动写 @get）
    • 提示效果：白星 / 白三角（可调大小）/ 无
    互动项没填跳转时，保存会自动建一个分支并接好「返回场景」的 @jump，不会再出现“点了没反应”。
    🔀 分支与流程图

    剧本里的「分支」= 以 ::名字 开头的段落。所有分支会出现在「分支」面板，也能切到流程图看结构。

    ::start 旁白：你先做什么？ - 看看桌子 -> desk - 直接开门 -> door ::desk 你找到一把钥匙。 @get 钥匙 @jump start

    流程图里拖动节点可以排版；按住节点左侧的绿色 ⇢ 圆点拖到另一个节点，就能直接建立一条跳转（自动写成 @jump），不用手敲标签。

    🧩 变量 / 物品 / 条件跳转
    @set 错误次数 0 @add 错误次数 1 @check 错误次数 >= 3 -> bad_end @has 钥匙 -> door_open @get 钥匙 @give 钥匙 @input 密码 请输入四位密码 @check 密码 == 1234 -> ok @end 圆满结局 你打开了门
    条件跳转的写法统一是 @check 变量 运算符 值 -> 标签，运算符支持 == != > < >= <=。

    🎞 致谢表与导出
    • 🎞 致谢表：纯文字 / 左图右文两种排版，可预览滚动，用 @credits 或在结局自动播放
    • 💾 导出：工程 JSON，可勾选只导一部分
    • 导出文件名会带上工程名称（设置 → 📁 工程名称，随时可改）
    • 🎮 导出游戏：单个 HTML，含所有图片音频（base64），双击即玩
    • 🎬 导出视频：自动播放并录屏，需要 https 或本地环境
    🌐 发布到网页 / 手机注意

    工具本身就是一张 HTML，传到任意静态托管（GitHub Pages、Cloudflare Pages、Vercel…）就能分享。要点：

    • 用 https 打开；本地双击（file://）会限制存储与录屏
    • 无痕模式 / 内嵌 iframe 里本地存储可能不可用，自动备份会失效，但其他功能正常
    • 手机横屏编辑更舒服，竖屏适合直接试玩

    编辑热点
    「跳转」填的是剧本里的标签名（如 ::开灯 就填 开灯）。不确定就让跳转留空，选中区域只给物品。
    写法：item:物品名 持有物品 · chose:选项文字 选过选项 · var:变量>=3 变量比较；用 and / or 连接多个。不填则不限制。
    🎮 互动场景制作器
    ① 先导入一张底图（比如教室、房间）
    ② 在图上手指/鼠标按住拖动框出一个可点击区域
    ③ 填上「点击后跳到哪个标签」（可直接选剧本里已有的标签）
    ④ 保存后勾选生成标签，一段能直接跑的骨架就写好了

    🎨 对话框自定义
    改的是舞台上的对话框（名字框 / 正文 / 头像框）。写 CSS 就行，改动即时预览，关掉窗口自动保存。
    写坏了就点「↺ 恢复默认」。
    角色名
    这是预览：边框、底色、圆角、宽度都可以改。
    可用选择器：.dialog 对话框盒子、.name 名字框、.text 正文、.avatarBox 头像框、.dialog.pos-top 上方位置。
    导出游戏时会自动换成对应的 #dialog / #name / #text 选择器，不用手动改。
